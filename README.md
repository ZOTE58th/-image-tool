# imgtool — 图片信息查看与简单编辑工具

一个用 Python 编写的命令行图片工具：读取图片基础信息，并对图片做缩放、裁剪、旋转、
翻转、灰度化和格式转换。所有编辑结果都另存为新文件，不会覆盖原图。

## 功能

| 命令 | 作用 |
| --- | --- |
| `info` | 查看文件名、格式、宽高、颜色模式、文件大小 |
| `resize` | 按宽高缩放，只给一边时按原比例缩放 |
| `crop` | 按左、上、右、下坐标裁剪 |
| `rotate` | 旋转 90 / 180 / 270 度 |
| `flip` | 水平或垂直翻转 |
| `gray` | 彩色图转灰度图 |
| `convert` | 转换图片格式，例如 PNG 与 JPG 互转 |
